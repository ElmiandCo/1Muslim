# Qibla homepage artwork

Upload your Qibla PNG as **qibla-home.png** into this folder.

Expected public path: `/assets/qibla/qibla-home.png`.

This is the background behind the two Magazine / Newsletter sections in the **homepage Qibla tab** only. It does not alter the actual Qibla editorial pages. A gradient fallback remains until the PNG is uploaded.

Use a portrait image for mobile (ideally 1440 × 2560 pixels), with the focal subject away from the center text. Transparent PNGs are supported.
