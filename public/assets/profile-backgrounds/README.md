# 1Muslim Profile Backgrounds

Upload four portrait images (prefer 864×1536 or 1080×1920, optimized PNG):

- `emerald.png` — default Emerald
- `rose-gold.png` — Rose Gold
- `silver-dust.png` — Silver Dust
- `carbon-fiber.png` — Carbon Fiber (night mode)

These images are used as optional parallax layers in the Home Profile background and as thumbnails in Profile → Background. If an asset is absent, the corresponding CSS gradient remains visible. The selected key is saved in the signed-in member's `profiles.avatar_config.profileBackgroundTheme`.

Keep imagery decorative, no text or UI baked into the artwork. Other Quran Studio or homepage artwork is not modified by this folder.
