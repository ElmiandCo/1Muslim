# 1Muslim Light Icons

Lightweight SVG icons for 1Muslim. No third-party dependency.

## React

```tsx
import PlayIcon from "@/app/components/icons/PlayIcon";

<PlayIcon width={24} height={24} style={{color:"currentColor"}} />
```

The icon inherits `currentColor` so it works with light/dark modes and theme colors. A raw SVG asset is available at `public/icons/1muslim-light/play.svg`.

Use the same 48×48 viewBox, thin rounded strokes, and transparent backgrounds for future additions.
