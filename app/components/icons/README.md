# 1Muslim Light Icons

A cohesive 48×48 futuristic outline icon kit: Play, Phone, Audio, Games and Qibla. All have transparent backgrounds, thin rounded strokes, and no icon-library dependency. Play, Phone, Audio and Games inherit `currentColor`. Qibla is a special two-tone pink/teal Kaaba compass mark.

```tsx
import PlayIcon from "@/app/components/icons/PlayIcon";
import PhoneIcon from "@/app/components/icons/PhoneIcon";
import AudioIcon from "@/app/components/icons/AudioIcon";
import GamesIcon from "@/app/components/icons/GamesIcon";
import QiblaIcon from "@/app/components/icons/QiblaIcon";

<PlayIcon width={24} height={24} />
<PhoneIcon width={24} height={24} />
<AudioIcon width={24} height={24} />
<GamesIcon width={24} height={24} />
<QiblaIcon width={24} height={24} />
```

The Play SVG asset is also at `public/icons/1muslim-light/play.svg`.
