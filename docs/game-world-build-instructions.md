# Nova — Jurassic World (priority 2)
Build a distinct selectable Jurassic reality, isolated from the historical worlds. Not a recreation of the Jurassic Park franchise, but an original prehistoric adventure.
- Large lush playable terrain, forests, rivers, mountains, waterfalls, rock caves, dramatic bright sky, physical collision and walkable ground.
- Animated prehistoric wildlife with predator/prey behavior, nearby-player AI, low-cost distant impostors, realistic sense of scale; dinosaurs should not be modern wildlife.
- Third-person free roaming, smooth camera, flight and Boost preserved, accessible touch and keyboard controls, multiplayer visibility.
- Three predator hits in 10 seconds => modern lobby respawn. Rocks, vegetation, terrain must be solid, without invisible barriers or fall-through.
- Portal to/from main lobby; distinct scene rendering and world state, preserve modern world and all other reality branches.
- Mobile-first optimization and level-of-detail. Do not use copyrighted franchise logos/assets.
- Implement on OWN branch only, run build/tests, preview, report SHA and limitations. Do not merge to main.
